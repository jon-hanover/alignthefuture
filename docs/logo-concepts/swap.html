Align the Future, vector color swap

Mark six with the top vector in tangerine and the lower vector in marine. Two ways to make the swap, with the chosen mark alongside for comparison.

Option 1

Whole swoosh orange

The A's left leg and the top vector are one stroke, so the simplest swap colors all of it tangerine. Leg and lower vector in marine. The A becomes two-tone, which is a real change to the letter.

Option 2

Orange above the apex only

The color changes exactly where the leg meets the swoosh, so the A stays all marine and only the vector that leaves it turns orange. The A reads as a letter first, then the two vectors read as two colors.
